# 从“猜最优”到“有条件的最优证明”

本轮实现了一个可运行的证明框架，以及现有策略的分歧见证。
**尚未证明实战大米、团本最高输出，也没有新增一个经过实战校准的伤害模型。**

## 1. 什么结论可以用数学证明

先固定相同的公开观测历史，把仍可能出现的局面记为 w。
对同一候选动作或完整策略 a，若其剩余战斗收益处于 [L(w,a), U(w,a)]，则：

```
R(a) = max_w max(0, max_{b != a} U(w,b) - L(w,a))
```

R(a) 是相对于所提供备选项的最坏收益损失上界。若 R(a)=0，则在这些局面、
这些备选项及这些有效边界的范围内，a 不劣于任何备选项。比较必须在同一局面内
进行，不能拿一个局面的下界减另一个局面的上界；也不能把 a 自身作为竞争项，
否则单个动作自身的不确定区间会制造虚假损失。

`scripts/optimality_bounds.py` 已用精确有理数实现这个检验。它拒绝缺失动作、
重复标识、反向区间、浮点 NaN 和不合格概率。计算器永远保留“仅限所提供收益表”
的证明范围，不会因为输入文件自称完整，就宣布真实游戏最优。
`synthetic-dominance.json` 还提供一个正例：现在爆发在两个示例局面内的收益下界
分别为 100、10，而保留的上界分别为 90、9；计算器确实给出 R=0 的条件证书。
这些边界同样只是数学示例，不是游戏伤害的可信边界。

## 2. 为什么“事后每次都最高”与“当时可作出的最好决策”不同

以下是数学示例，数字不是 WoW 技能系数或战斗测量值。

| 同样公开历史后出现的未来 | 现在爆发 | 保留爆发 |
|---|---:|---:|
| 战斗很快结束 | 100 | 0 |
| 后续增援到来 | 100 | 180 |

第一个未来必须现在爆发，第二个未来必须保留。相同观测下没有一个选择能同时
达到两个未来各自的最高值；随机选择也不能保证每次成功。验证器得到共同最优
集合为空。现在爆发的最坏损失上界为 80，保留为 100。

如果明确假设两个未来的概率分别为 4/5、1/5，期望收益变为 100、36；此时
“现在爆发”在这个给定模型中期望最优，但仍会在第二种未来落后。概率是示例的
输入，不是从实战估出的结论。真实 WoW 是否存在具体不可区分且最优动作相反的
状态，需要实际游戏模型与观测证据；这个小例子只证明一般的信息限制。

多阶段场景还有一个容易漏掉的陷阱：不能先让每个模拟世界的后续动作偷看未来，
再把这些最高收益加权，称为玩家的最优决策。候选必须是同一套不预知未来的
完整策略，或者对部分可观测模型求解。否则只是全知上界。

## 3. 真正接入插件的内容

`IndependentConsensus` 现在最多输出两个导致不同动作的区间见证，包括等待。
`IndependentObserver` 转交证明范围、策略是否一致和这些见证。它们是优先级
求解器数值抽象中的可行区间，**不是恢复出来的秘密值，也不保证对应物理可达
的真实角色状态**。公开事实相同不代表隐藏状态已经被识别。

`shipped-policy-witnesses.tsv` 使用实际交付的两份策略，在明确构造的公开输入下
生成分歧：魔痕可选邪能之刃或复仇回避，奥达奇可选歼灭或混乱打击。输入人为
设定技能已学、就绪，以定位规则不确定性；这不是游戏战斗日志。

这些见证的用途是定位会改变推荐的未知量，指导下一步补模型或观测。所有可行
补全都选同一个动作，只能证明该策略在这些补全上动作一致，不能证明伤害最高。

## 4. 现有伤害证据不支持“已经最高”

重算既有保留种子结果，核对 40 份唯一原始报告的 SHA-256，共 20 个比较。
比较对象为当前交付策略与完整参考循环，不是上一轮未采用的候选。

- 魔痕均值约为参考的 91.88%–98.60%。
- 奥达奇均值约为参考的 93.73%–97.36%。
- 20 个比较中，参考均值差减去双方标准误之和的三倍仍为正。

最后一项只是描述性筛查，不是多重比较的同时置信定理；这些结果仍是固定
build 的离线 SimC 数据，不能当成真实副本成绩或所有玩家的伤害界限。
原始来源、比较数值与范围见 `existing-benchmark-audit.json`。

## 5. 复现与下一步证明条件

```
python scripts/optimality_bounds.py research/optimality-evidence/synthetic-worlds.json
python scripts/audit_optimality_evidence.py --output research/optimality-evidence
lua scripts/run_tests.lua consensus_evidence
python -m pytest tests/test_optimality_bounds.py tests/test_consensus_witness_property.py -q
python scripts/mutate_optimality_evidence.py --output dist/research/optimality-evidence/mutations
```

新增测试覆盖精确收益表穷举、区间上界、显式概率，以及生成的区间见证独立回放。
9 个故意损坏证明逻辑的变异均被拒绝。安装包默认与优先级规则不变。

真正的实战证明仍需要：版本匹配的伤害/状态转移模型；同一公开历史下所有相关
隐状态的覆盖；合法候选及其可执行后续策略；可信的收益上下界；实际观测覆盖率
与延迟；副本机制、走位和重点目标约束；以及独立实战对照。当前未找到可运行的
本地 WoW 客户端，不能执行最后的游戏内验收。
