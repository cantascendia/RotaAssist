这一版修复什么

  • 按当前原生动作按钮读取按键，翻页和天赋替换后重新解析。
  • 默认立即切换推荐纹理；超距有文字提示，可减少图标动画。
  • 没有推荐时清除旧图标并显示状态，未知置信度不再给满星。
  • 提供实战专注和学习视图；图标不拦截主条拖动、右键操作。

进入游戏后检查什么

  • 中英日字体、长按键、多种界面缩放和超宽屏是否清晰。
  • 按键翻页、天赋替换、超距和打断提示是否与游戏一致。
  • 大米拉怪与团本机制下的提示跳变、漏推荐、CPU 和帧率。
  • 第三方动作栏和条件宏的绑定支持；本版对无法确认的绑定留空。
模型边界：布局评审和自动化测试不能证明实战最高输出。当前固定 build 的离线对照仍有差距；实战采样用于定位缺失信息，不等于伤害测量。
