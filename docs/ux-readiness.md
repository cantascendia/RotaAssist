# 实战界面验收与改进

本轮范围：修复会误导操作的按键提示；使推荐更新不必等待动画；限制文本越界；为无推荐和超距提供文字状态。保持现有用户配置、引擎输出及实验模式开关。

验收要求：

- 按键取自当前原生动作按钮的实际 action 和 bindingAction，支持翻页、额外动作栏、当前技能替换以及 CLICK 绑定。未知或受限值不推测；条件宏和第三方动作栏尚不承诺支持。
- 正向、负向查询都缓存；动作栏、绑定、变身、天赋和进入世界时失效。原生事件回调先后顺序不得导致长期错误缓存。
- 默认减少推荐图标动画：技能纹理立即替换，保留静态边框和超距文字。关闭此选项仍支持现有淡入和脉冲。
- 关闭 proc 高亮必须真正关闭高亮；未知预测置信度不能显示最高星级。
- 快捷键和来源标记限制在图标内。组合键先缩到最小字号，仍放不下则留空，不能截成错误的按键。超距同时有文字与颜色，颜色不是唯一判断依据。
- 无推荐时清除旧主技能，并显示“等待推荐”；目标不存在时显示“选择目标”。不得把读取失败解释为可攻击。
- 英文、简体中文、日文均提供相应设置与状态文案。

离线测试只证明逻辑、状态和生命周期，不能证明 WoW 字体渲染、第三方插件兼容、战斗性能或实战 DPS。本机已有版本匹配的 WoW 12.1.0.69875 可执行文件；用户确认仍在下载，游戏内验收仍待完成。

验收采样：`/ra capture on` 开始一份新记录，`/ra capture off` 停止。默认关闭，最多保留最近 1200 个事件；推荐每 0.5 秒采样一次，施法和战斗阶段事件独立记录。只保存公开且类型验证通过的字段，不记录玩家姓名、GUID、聊天或秘密资源。角色记录包含 build 标识及其完整性，而非全量伤害模型。记录归入当前配置的 SavedVariables，重载/正常退出后可读；重新启用采样会覆盖旧记录。采样不能作为完整战斗日志、精确反应时间或伤害最优证明。

采样格式 `rotaassist.combat-audit.v1`：`events` 是环形缓冲，按 `sequence` 排序恢复时间顺序；`dropped` 标出已覆盖事件数。`queueSpellID` 是事件分发时引擎队列中的技能，不能直接当作玩家施法前看见的技能。相同事件的其他订阅者可能已刷新队列，因此不得用它计算毫秒级反应时间。目标数量仍是公开近战范围探针的下界，`countComplete=false` 不可当作精确总怪数。build 标识最多保留 16 份，超过后保留 generation，但不绑定错误的 buildIndex。设置变更或插件停用会停止采样；重新登录不会自动开启。

## 上手与界面审计结果

| 问题 | 本轮处理 | 剩余验收 |
| --- | --- | --- |
| 翻页、额外动作栏提示错误按键，缓存反复扫描 | 原生按钮实际 action/bindingAction + 正负缓存 + 事件失效 | 当前游戏版本、第三方动作栏 |
| 主技能切换先淡出，暂时展示旧纹理 | 默认减少图标动画，即时替换，切换选项时完成待更新纹理 | 游戏内帧时间与延迟 |
| 图标 Button 拦截拖动/右键 | 非交互提示图标放行鼠标给主条 | WoW 实际命中测试 |
| 多个教练面板抢占视线 | 一键实战专注 / 学习视图；保持位置和推荐模式 | 团本机制时视线占用 |
| 未知置信度默认满星、高亮开关失效 | 未知不显示星级，开关控制真实 proc 高亮 | 不同天赋/触发状态 |
| 空队列留白或残留旧图标 | 清空过期技能和预测，显示目标/等待状态 | 目标切换与重连 |
| 超距只靠颜色，按键文本越界 | 超距文字，文本宽度约束与禁止换行 | 中英日字体、手柄及长组合键 |

`ux-preview.html` 为可交互布局评审页，使用占位图标和示例资源值，不是实际插件截图。浏览器检查只能验收此预览本身。

动作栏接口依据：[Blizzard ActionButton 源码镜像](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_ActionBar/Shared/ActionButton.lua)。本轮不写入受保护按钮，不执行技能。
