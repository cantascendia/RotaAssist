# RotaAssist 1.1.1-rc.17

本轮改善实战提示的正确性、响应速度和上手体验，并加入可选本地战斗采样。独立伤害策略与实验开关默认值未改变，不能宣称已经达到实战理论最高输出。

- 按键改为读取当前原生动作按钮的实际槽位、绑定和技能替换。缓存支持有/无绑定结果，并在翻页、绑定、变身和角色变更后失效。覆盖动作栏生效时不显示可能错误的普通主条绑定。条件宏和第三方动作栏尚不承诺支持。
- 推荐图标默认即时更新；减少图标动画时使用静态提示。超距有文字标识，快捷键和来源文本限制宽度。图标不再拦截主条鼠标操作。
- 实战专注和学习视图只改变显示项，保留位置、安全警报及推荐模式。空队列清除旧技能并显示等待/选择目标；未知预测置信度不再显示满星。
- `/ra capture on|off` 可采样公开决策、施法事件、build 标识与缺失信息，最多 1200 个事件和 16 份 build。默认关闭；无姓名、GUID、聊天或秘密资源字段。样本不是精确反应时间或 DPS 测量。

安装步骤见 `START-HERE.md`；详细审计见 `docs/ux-readiness.md`；浏览器布局示意见 `docs/ux-preview.html`。布局示意不使用真实客户端纹理，不替代游戏内验收。

离线验证：787 条 Lua、131 条 Python 测试通过；19 个故意损坏行为的变异全部被测试拒绝。新增测试为 Test-Lock 场景 3，仅新增覆盖；已有断言保持不变。浏览器核对了占位预览的专注视图、学习视图、超距与无目标状态，不能替代 WoW 渲染验收。
